# The Day in Numbers — Sunday 22 November 2026

A data-led poster of Sunday 22 November 2026: six huge numerals, each one a
verified story of the day, in a clean 2 x 3 grid under the masthead
"SUNDAY 22 NOVEMBER 2026 — THE DAY IN NUMBERS".

- **128** — Rishabh Pant's runs for India against New Zealand in Wellington
- **83** — years of Lebanon's independence
- **723** — seats in Hong Kong's Election Committee vote (856 candidates)
- **06:00** — GMT, when the COP31 approval session opens in Antalya
- **16:30** — kickoff, Liverpool v Manchester United at Anfield, Mauricio
  Pochettino's first game in charge of United
- **4TH** — weekend in a row of cost-of-living protests in France

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024 x 1024, deterministic, standard library only).
